Financial: the mega-advisor who breaks the model

99% of advisors have a few hundred clients and embed fine. Then there's the institutional book with 100,000 clients. The Outlier pattern adds a flag, an overflow collection, and an if in your application — the 16 MB limit leaking into your code.

Document — the model admits it breaks for the fat tail

const a = db.advisors.findOne({_id: id})
let clients = a.clients
if (a.hasOverflow) {                 // the leak
  clients = clients.concat(
    db.overflow.find({advisor: id})
              .toArray())
}
// two code paths, two failure modes,
// forever — because one advisor is big.

Converged — the outlier is just more rows

-- advisor_clients partitioned/indexed by advisor
SELECT client_id, market_value
FROM   advisor_clients
WHERE  advisor_id = :whale
ORDER BY market_value DESC
FETCH FIRST 100 ROWS ONLY;
-- CBO adapts the plan for the whale vs the
-- typical advisor. One query. No branch.

There is no fat tail when the row is the unit, not the document. Embed the bounded common case, reference the overflow, and let a duality view re-join them — but on a relational base the outlier never needed special-casing at all. The optimizer plans for it.

Pattern 6, Outlier — the punchline is 'the 16 MB limit leaking into your application code.' That's the quotable line.

▸ The setup: 99% of advisors embed fine; the institutional book has 100,000 clients and blows the document.
▸ The hard edge (hot JS): the Outlier pattern adds a hasOverflow flag, an overflow collection, and an if-branch in your app. Two code paths, two failure modes, forever — because one advisor is big. That's the doc-size limit leaking into code.
▸ The softening (cool SQL): on a relational base the outlier is just more rows. One query, ORDER BY market_value DESC FETCH FIRST 100, partitioned/indexed by advisor. The CBO adapts the plan for the whale vs the typical advisor — no branch.
▸ The hybrid option: embed the bounded common case, reference the overflow, let a duality view re-join — but note that on relational the outlier never needed special-casing.

Land: there is no fat tail when the row is the unit, not the document. The optimizer plans for it.
